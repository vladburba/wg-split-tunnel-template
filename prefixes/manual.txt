# Ручные префиксы — для случаев, когда сервис живёт НЕ в собственной AS.
#
# Читается aggregate_prefixes.py всегда, независимо от services.conf.
# fetch_prefixes.sh этот файл не трогает — он пишет только as<номер>.txt.
#
# Формат: один префикс на строку, IPv4 и IPv6 вперемешку.
# Строки с # и пустые игнорируются.
#
# Когда это нужно: сервис размещён на общем CDN (Cloudflare, Fastly, Akamai,
# CloudFront), где один IP обслуживает тысячи чужих сайтов. Добавить всю AS
# такого CDN нельзя — утащишь в туннель пятую часть интернета. Но если
# провайдер сервиса публикует свой выделенный блок внутри CDN — его можно
# взять точечно. Именно этот случай ниже.

# --- GitHub: часть инфраструктуры отдаётся через Fastly (AS54113) ---
# Источник: https://api.github.com/meta (поля web и api)
# Покрывает raw.githubusercontent.com и objects.githubusercontent.com —
# оттуда качаются релизные бинарники, LFS-объекты и содержимое файлов.
